** Project overview
cfDNA copy number analysis biopipe using ichorCNA and Fragle. Processes a configurable matrix of {library} x {window} x {pon} x {preset} combinations for comprehensive CNA profiling from cell-free DNA.

* cfDNA CNA workflow
** Background
cfDNA copy number analysis uses read depth from shallow whole-genome sequencing to infer somatic copy number aberrations. ichorCNA is the standard tool for estimating tumor fraction and CNA from cfDNA. Fragle provides an orthogonal ctDNA fraction estimate from fragment length distributions.

Fragment length filtering enriches for tumor-derived cfDNA (shorter fragments), potentially improving sensitivity. This pipeline systematically evaluates the effect of different fragment windows on CNA calling.

** Fragment length filtering
Two rules handle fragment filtering:
- =cna_fragment_filter=: Filters BAM by TLEN using samtools view expression filter
- =cna_fragment_filter_full=: Symlinks original BAM for the =full= (unfiltered) window

The =full= window rule has priority via =ruleorder= to avoid ambiguity.

** BAM to WIG
=cna_bam_to_wig= uses HMMcopy's =readCounter= to generate 1Mb-binned WIG files from filtered BAMs. Chromosome list is configurable (NCBI or UCSC style).

** Panel of normals
Two rules handle PoN generation:
- =cna_pon_wig_list=: Aggregates normal sample WIG paths into a text file
- =cna_build_pon=: Runs =createPanelOfNormals.R= from ichorCNA-patched

Custom PoNs are built per-window to avoid calibration mismatch with fragment-filtered tumor samples.

** ichorCNA
=cna_run_ichor= runs ichorCNA with configurable presets and conditional PoN. The PoN input function returns an empty list for =nopon=, causing the =--normalPanel= flag to be omitted. Pre-built PoN paths are used directly; custom PoNs are resolved as DAG dependencies.

** Fragle
=cna_run_fragle= runs Fragle ctDNA quantification on filtered BAMs. Output is per {library}.{window} only (no PoN/preset dimension since Fragle is independent of ichorCNA parameters).

** TF extraction and aggregation
- =cna_extract_ichor_tf=: Parses ichorCNA =.params.txt= to extract tumor fraction and ploidy
- =cna_aggregate_results=: Merges all ichorCNA TF TSVs and Fragle CSVs into a single comparison table

** Visualization
Four visualization rules produce PDF and PNG outputs:
1. TF comparison plot (ichorCNA vs Fragle, faceted by window)
2. LogR heatmap (genomic bins x samples, per pon/preset)
3. Window concordance (TF across windows per sample)
4. Fragle summary (ctDNA fraction per sample per window)

* Testing
** Test data provenance
Chr22-only BAMs from the frag repo test data. These provide DAG/integration testing only --- ichorCNA and Fragle produce biologically meaningless results on single-chromosome data.

** Test matrix
With test.yaml: 1 tumor (lib002) x 2 windows (90_150, full) x 2 PoN (nopon, custom) x 1 preset (default-low-input) = 4 ichorCNA jobs, 2 Fragle jobs, plus PoN builds, aggregation, and visualizations (29 total jobs).

* Calibration notes
** PoN/window mismatch warning
A panel of normals built on unfiltered reads should not be used with fragment-filtered tumor BAMs, and vice versa. The pipeline enforces this by building custom PoNs per-window. Pre-built PoNs are the user's responsibility to match.

** ichorCNA default PoN
The shipped =HD_ULP_PoN_1Mb_median= was built on unfiltered reads. Using it with fragment-filtered BAMs introduces systematic bias. Recommend =nopon= or custom PoN for filtered windows.
