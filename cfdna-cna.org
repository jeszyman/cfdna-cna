** Project overview
cfDNA copy number analysis biopipe using ichorCNA and Fragle. Processes a configurable matrix of {library} x {window} x {pon} x {preset} combinations for comprehensive CNA profiling from cell-free DNA.
** Key files
- =workflows/cna.smk= — Main modular snakefile (all rules)
- =workflows/test.smk= — Test wrapper with config loading and rule all
- =config/common.yaml= — Production config with full parameter matrix
- =config/test.yaml= — Test config (chr22 only, minimal matrix)
- =scripts/= — R and Python scripts for TF extraction, aggregation, visualization

*** Fragment length filtering

Two rules handle fragment filtering. =cna_fragment_filter= filters by TLEN using awk (the samtools =-e= expression filter is unreliable across builds). =cna_fragment_filter_full= symlinks the original BAM for the =full= (unfiltered) window. The =full= window rule has priority via =ruleorder=.

#+begin_src snakemake
# ---------------------------------------------------------------------------
# Rule 1a: Fragment filter (sized windows)
# ---------------------------------------------------------------------------
rule cna_fragment_filter:
    """Filter BAM by fragment length (TLEN) for a specific window."""
    input:
        bam=get_bam,
    output:
        bam=f"{D_CNA}/filt_bam/{{library}}.{{window}}.bam",
        bai=f"{D_CNA}/filt_bam/{{library}}.{{window}}.bam.bai",
    params:
        frag_min=lambda w: w.window.split("_")[0],
        frag_max=lambda w: w.window.split("_")[1],
    log:
        f"{D_LOGS}/{{library}}.{{window}}_fragment_filter.log"
    benchmark:
        f"{D_BENCHMARK}/{{library}}.{{window}}_fragment_filter.tsv"
    threads: 4
    conda: ENV_ICHOR
    wildcard_constraints:
        window=r"\d+_\d+"
    message: "Fragment filtering {wildcards.library} to {wildcards.window}"
    shell:
        """
        samtools view -h -@ {threads} {input.bam} | \
          awk -v min={params.frag_min} -v max={params.frag_max} \
          'BEGIN{{OFS="\t"}} /^@/{{print;next}} {{t=$9; if(t<0)t=-t; if(t>=min && t<=max)print}}' | \
          samtools sort -@ {threads} -o {output.bam} 2> {log}
        samtools index {output.bam} 2>> {log}
        """

# ---------------------------------------------------------------------------
# Rule 1b: Fragment filter (full window — symlink)
# ---------------------------------------------------------------------------
rule cna_fragment_filter_full:
    """Symlink BAM for full (unfiltered) window."""
    input:
        bam=get_bam,
        bai=lambda w: get_bam(w) + ".bai",
    output:
        bam=f"{D_CNA}/filt_bam/{{library}}.full.bam",
        bai=f"{D_CNA}/filt_bam/{{library}}.full.bam.bai",
    log:
        f"{D_LOGS}/{{library}}.full_fragment_filter.log"
    benchmark:
        f"{D_BENCHMARK}/{{library}}.full_fragment_filter.tsv"
    message: "Symlinking full BAM for {wildcards.library}"
    shell:
        """
        ln -sf $(readlink -f {input.bam}) {output.bam} 2> {log}
        ln -sf $(readlink -f {input.bai}) {output.bai} 2>> {log}
        """

ruleorder: cna_fragment_filter_full > cna_fragment_filter
#+end_src

*** ichorCNA

=cna_run_ichor= runs ichorCNA with configurable presets and conditional PoN. The =get_pon_input= function returns an empty list for =nopon=, causing the =--normalPanel= flag to be omitted. Pre-built PoN paths are used directly; custom PoNs are resolved as DAG dependencies.

#+begin_src snakemake
# ---------------------------------------------------------------------------
# PoN input resolution
# ---------------------------------------------------------------------------
def get_pon_input(wildcards):
    """Return PoN RDS path as a list (empty for nopon)."""
    pon_cfg = PON_CONFIGS[wildcards.pon]
    if pon_cfg.get("prebuilt-path"):
        return [pon_cfg["prebuilt-path"]]
    elif pon_cfg.get("normal-samples"):
        return [f"{D_CNA}/pon/{wildcards.pon}.{wildcards.window}_median.rds"]
    else:  # nopon
        return []

* Testing
** Test data provenance
Chr22-only BAMs from the nuc-pos repo test data (originally from frag repo). These provide DAG/integration testing only --- ichorCNA GC loess correction fails on chr22-only data (~28 valid bins at 1Mb is below the loess span threshold), and Fragle requires all chromosomes present in the BAM.
** Test matrix
With test.yaml: 1 tumor (lib002) x 2 windows (90_150, full) x 2 PoN (nopon, custom) x 1 preset (default-low-input) = 4 ichorCNA jobs, 2 Fragle jobs, plus PoN builds, aggregation, and visualizations (29 total jobs).
* Phase 2
** WisecondorX (future)
Z-score-based CNA caller ([[https://github.com/CenterForMedicalGeneticsGhent/WisecondorX][GitHub]]). Would add =cna_run_wisecondorx= rule producing =.bed= CNA segments. New conda env (Python). Parallel output path under ={D_CNA}/wisecondorx/=. Uses within-sample reference bins with matching GC/mappability for normalization.
** BayesCNA (future)
Bayesian changepoint detection for low-purity samples ([[https://github.com/lottaer/BayesCNA][GitHub]]). Would add =cna_run_bayescna= rule. R-based, could share ichor env. Designed to increase recall at the 1-3% TF detection boundary where ichorCNA is unreliable.
* Calibration notes
** PoN/window mismatch warning
A panel of normals built on unfiltered reads should not be used with fragment-filtered tumor BAMs, and vice versa. The pipeline enforces this by building custom PoNs per-window. Pre-built PoNs are the user's responsibility to match.
** ichorCNA default PoN
The shipped =HD_ULP_PoN_1Mb_median= was built on unfiltered reads. Using it with fragment-filtered BAMs introduces systematic bias. Recommend =nopon= or custom PoN for filtered windows.
